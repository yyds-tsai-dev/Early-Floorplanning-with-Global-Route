## Q7. ILLEGAL_FT（WARNING）與 ILLEGAL_INTERNAL_TURN（ERROR）述詞重疊（2026-07-30 新增）

`E_reference_20260727.html` §Error/Warning 中：

- `ILLEGAL_INTERNAL_TURN`（**ERROR → FAIL**）：「MACRO/EDGE block 在 PATH
  中間發生內部轉折**或直穿**；同 rect 進出 edge1≠edge2，或同 edge 進出」；
- `ILLEGAL_FT`（**WARNING + λ_ft penalty**）：「MACRO/EDGE block 被用作
  feedthrough（出現在 PATH 中間）……不判定 FAIL」。

MACRO/EDGE 出現在 PATH 中間必然落入前者的述詞（進出同 edge 或不同 edge
皆被列舉）,兩條規則對同一行為給出相反判定。想確認實際判定順序/優先權：
MACRO/EDGE 作為 feedthrough 時,checker 會（a）僅記 ILLEGAL_FT WARNING
並繼續,還是（b）觸發 ILLEGAL_INTERNAL_TURN 直接 FAIL？

（背景：A1 說「以扣分計,非直接 fail」,但在釐清前我們一律不讓路徑
穿越 MACRO/EDGE。）
